# AI编程机制解析：Claude Code 与智能体交互原理

## 核心概念 [原片 @ 00:50](https://www.bilibili.com/video/BV1AuzkBREhx?t=50)

### 模型 vs 智能体的本质区别
*   **大模型**：本质是基于概率预测下一个 token。知识存在截止期（如 GPT-3.5 训练截止于 2021 年 9 月），无法直接获取实时信息或操作文件。
*   **智能体**：为了解决大模型无法自主获取信息或执行操作的问题而诞生。本质上是“智能爬虫”，通过循环执行特定步骤来完成复杂任务。
*   **Cursor Code**：一种 AI 编程智能体，通过与大模型的远程“问诊”配合，实现代码调试与修复。

### 智能体的循环逻辑
无论智能体执行多少次请求，其核心循环仅包含三件事：
1.  **收集信息**：获取上下文。
2.  **解析结果**：从大模型返回中提取执行指令。
3.  **执行操作**：执行指令并将结果反馈给大模型。

## 方法与步骤 [原片 @ 05:00](https://www.bilibili.com/video/BV1AuzkBREhx?t=300)

### 1. 提示词构建
在 Cursor Code 进行诊断前，必须构建包含以下内容的完整提示词包：
*   **用户问题**：明确指出错误文件和期望的修复目标。
*   **系统提示词**：定义 AI 的角色（如“编码专家”）和行为边界（如“不要解决用户的心理问题”）。
*   **工具列表**：告诉 AI 在解决问题时可以调用的工具集。
*   **历史记录**：模拟“病历本”，记录之前的对话、请求和结果，确保上下文连贯。

### 2. 交互诊断流程（以修复 Hello.java 为例）
*   **Step 1: 首次诊断**
    *   智能体将提示词包发送给大模型。
    *   大模型判断无法直接定论，返回工具调用指令：读取 `Hello.java`。
*   **Step 2: 执行读取**
    *   智能体执行读取文件操作。
    *   智能体将文件内容、历史记录、系统提示词和工具列表再次发送给大模型。
*   **Step 3: 二次诊断**
    *   大模型检查语法无误，但发现引用了 `Search` 类。
    *   大模型返回工具调用指令：搜索 `Search` 类。
*   **Step 4: 执行搜索**
    *   智能体执行搜索，获取 `Search.java` 的路径。
*   **Step 5: 第三次诊断**
    *   智能体读取 `Search.java` 内容，连同之前的 `Hello.java` 和历史记录一起发送。
    *   大模型对比发现 `Hello` 中调用的构造函数缺少参数，返回最终解决方案。

## 常见误区/注意事项 [原片 @ 05:50](https://www.bilibili.com/video/BV1AuzkBREhx?t=350)

### 模型不直接访问文件系统
**误区**：认为 AI 会直接解析用户提示词并读取文件。
**真相**：大模型本身不具备文件系统访问能力。它只能返回工具调用指令（如“读取文件 X”），由智能体（Cursor Code）去执行实际的文件读写。

### 智能体不自己思考，只负责执行
**误区**：认为智能体会像人一样分析代码。
**真相**：智能体只是一个“传声筒”和“执行者”。它把所有信息打包发给大模型，大模型做所有的逻辑判断，智能体只负责调用工具。

### 忽略历史记录的重要性
在多轮交互中，每次发送给大模型的内容都必须包含之前的**历史记录**。这就像看病，医生需要知道你之前做了哪些检查，才能判断下一步。

## 实操要点 [原片 @ 06:30](https://www.bilibili.com/video/BV1AuzkBREhx?t=390)

### 系统提示词的编写
系统提示词通常包含以下段落：
1.  **身份定义**：你是 Cursor Code 的编码专家。
2.  **任务定义**：解决编码问题。
3.  **约束条件**：不要处理心理或个人生活问题。
4.  **方法论**：告诉大模型如何解决问题（如“通过阅读文件、搜索资料来定位问题”）。

### 工具列表的配置
Cursor Code 的工具列表包含 17 个工具，核心工具包括：
*   **定义任务**
*   **任务输出**
*   **读取文件**：用于获取代码内容。
*   **编辑文件**：用于修改代码。
*   **写入文件**：用于创建新文件。
*   **搜索**：用于查找文件或代码片段。

### 请求包结构
每次请求（除了第一次规划外）都应包含：
1.  **历史记录**（上下文）
2.  **当前待处理的内容**（如读取到的文件、搜索结果）
3.  **系统提示词**
4.  **工具列表**

## 术语与速查 [原片 @ 08:00](https://www.bilibili.com/video/BV1AuzkBREhx?t=480)

*   **NGT (Next-Gen Agent)**：早期智能体概念，通常指早期的爬虫式智能体。
*   **System Prompt**：系统提示词，定义 AI 的角色、任务和约束。
*   **Tool Call / Tool Use**：工具调用，大模型返回的指令，指示智能体执行特定操作。
*   **Context / History**：上下文/历史记录，维持对话连贯性的关键。
*   **Token**：大模型处理文本的基本单位。
