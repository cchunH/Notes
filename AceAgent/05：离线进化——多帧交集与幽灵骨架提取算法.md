## 1. 核心定义与设计思辨 (Core Definition & Speculation)

### 1.1 “做梦”的工程意义
人类在睡眠时会整理白天的记忆，强化重要连接，遗忘噪声。AceAgent-Swarm 的**离线进化层 (Evolution Layer)** 扮演同样的角色。
*   **在线时 (Online)**：追求极致速度，只做匹配和执行，不进行深度分析。
*   **离线时 (Offline)**：追求极致精度，调用大算力（或云端集群）对历史 Trace 进行“考古”，提取高置信度的锚点。

### 1.2 幽灵骨架 (Ghost Skeleton)
对于一个动态 App 页面，如果我们剥离掉所有随时间变化的因素（时间戳、广告、Feed 流内容、用户头像），剩下的那个**拓扑结构**，就是该页面的“灵魂”。
我们称之为 **幽灵骨架 (Ghost Skeleton)**。它是 State Plane 匹配的终极参照物。

## 2. 算法流程：差分分析器 (The Differential Analyzer)

该算法的核心思想是**“基于集合论的差分运算”**。

### 2.1 输入数据：Trace Log
系统输入是过去 $N$ 次成功执行某任务（如“微信发消息”）的完整日志集合 $T = \{t_1, t_2, ..., t_n\}$。
每个 $t_i$ 包含：
*   **Raw Screenshot**: 原始截图。
*   **DOM/AXTree Dump**: 当时的 UI 树。
*   **Action Metadata**: 执行动作的坐标与意图。

### 2.2 第一步：基于结构的聚类 (Structural Clustering)
首先，必须确保我们对比的是“同一个页面”。
*   **Hash 签名**：计算 DOM 树中所有 `Container` 类节点的路径 Hash。
*   **聚类逻辑**：将 $T$ 中结构相似度 $> 80\%$ 的日志归为一类（Cluster）。
    *   *注：这能自动区分“微信首页”和“微信聊天详情页”，无需人工打标。*

### 2.3 第二步：多帧交集运算 (Multi-frame Intersection)
对于同一个 Cluster 内的 $k$ 张快照，进行节点级交集：

$$Node_{static} = \bigcap_{i=1}^{k} Nodes(t_i)$$

*   **属性恒定性检查**：
    对于一个节点（如某个 TextView），检查其 `text` 属性在 $k$ 帧中是否变化。
    *   如果 $text$ 始终为 "微信"，标记为 **Static (静态)**。
    *   如果 $text$ 分别为 "10:00", "10:01", "12:30"，标记为 **Dynamic (动态)**。

### 2.4 第三步：动态区域剔除与槽位标记 (Dynamic Pruning)
*   **剔除**：直接从骨架中删除所有被标记为 Dynamic 的节点（如时间、电量、聊天内容）。
*   **槽位 (Slotting)**：如果某区域虽然内容在变，但位置和层级永远固定（比如 Feed 流的容器 `RecyclerView`），将其标记为 **Variable Slot (变量槽)**。
    *   *用途*：在线匹配时，Slot 区域内的任何变化都会被忽略，不会降低匹配置信度。

## 3. 进阶机制：应对复杂场景 (Advanced Mechanisms)

### 3.1 A/B 测试的分叉管理 (Forking for A/B Tests)
如果 App 进行了灰度发布，部分用户的“我的”页面多了一个“直播”入口。
*   **现象**：交集运算发现 Cluster 内部出现了分裂，30% 的快照有该入口，70% 没有。
*   **决策**：进化层自动执行 **Fork (分叉)** 操作。
    *   生成 `Skeleton_Ver_A` (无入口版)
    *   生成 `Skeleton_Ver_B` (有入口版)
    *   在线执行时，Agent 会尝试匹配任意一个，哪个匹配分高用哪个。

### 3.2 合成数据增强 (Synthetic Augmentation)
为了让在线匹配算法（文档二）更鲁棒，离线层会制造“假数据”来训练匹配阈值。
*   **扰动生成**：对提取出的标准骨架进行随机扰动。
    *   坐标随机偏移 $\pm 5px$。
    *   随机删除 1-2 个非核心锚点（模拟遮挡）。
*   **训练目标**：调整在线匹配算法的参数，确保即使在这些“恶劣条件”下，骨架依然能被召回。

## 5. 总结 (Summary)

离线进化层是 AceAgent-Swarm 的**“时间机器”**。它将过去无数次的操作经验，压缩为几十 KB 的静态骨架。
正是因为有了这个机制，Agent 才能在看似混乱的动态 UI 中，拥有“透视眼”，直接看到页面不变的本质结构。
